# Bench headline is binary Pass, not a quality score

v1 exposes the full Action catalog on every Task; difficulty lives in the query and start state. The published number is Pass count / rate (and pass^k). Partial checks (window slack, process flags) stay diagnostic so RL can reuse them later without changing what “the bench says.”

A 0–100 rubric or “how balanced” scalar would become the object people optimize and would not match nutrient-window oracles.

**Status**: accepted
