# NutriEnv v2.2-Gold 审计与修复闭环报告

## 一、 背景与审查概述
通过 Herdr 调度 **Claude Opus** 与 **Grok** 对 `data/splits/v2.2-gold.json` 及全流程评测体系进行独立背靠背审查（Dual-Agent Review）。
两位审查者一致给出 **`revise`** 裁决：
- **题目数据本身质量极佳**：100/100 题目在物理上 100% 绝对可解（`check_achievable` 0 异常），无幽灵食物、无佐料单餐、无官僚化标签，过敏与营养约束全面满足 ADR 0024 的 5/15/20/20/40 标准矩阵。
- **评测与元数据层存在 5 项核心缺陷**：判分器未实现 ADR 0023 物理白名单容差、枚举类缺失幂等标签、官方版本标识未发布、复合题元数据缺少难度梯队分层、评测脚本 Tag 不一致。

## 二、 修复落地明细

### 1. 判分器物理白名单离散容差（`src/nutrienv/bench/scorer.py`）
- **问题**：原判分器对 `LedgerRow` 克数进行浮点全等比对，当 Agent 推断出同等合理的 FNDDS 白名单份量（如 180g vs 200g，处于 $\pm 15\%$ 容差内）时被误判为 0 分（产生假阴性）。
- **修复**：
  - 引入 `matches_portion_table`。
  - 在 `_ledger_row_matches` 与 `_match_ledger_multiset` 中实现 ADR 0023 双条件容差门禁：
    $$0.85 \times \text{Gold} \le \text{Grams} \le 1.15 \times \text{Gold} \quad \text{且} \quad \text{matches\_portion\_table}(\text{food\_id}, \text{Grams}) == \text{True}$$
  - 在 `tests/test_scorer.py` 中补充容差命中与非白名单拒绝的单元测试。

### 2. 补充 `idempotent_update` 枚举并给数据集打标
- **问题**：`situations.py` 未定义 `idempotent_update`，导致 ADR 0023 规定的幂等交互题目无法被标定和针对性测试。
- **修复**：
  - 在 `src/nutrienv/bench/situations.py` 中添加 `Situation.IDEMPOTENT_UPDATE = "idempotent_update"`。
  - 在 `data/splits/v2.2-gold.json` 与 `v2.2-mini.json` 中给 `adr20-upd-5026`、`adr24-comp-9200`、`adr24-comp-9503` 打上 `situations: ["idempotent_update"]`。

### 3. 正式注册发布 v2.2 考卷版本
- **问题**：Split 文件版本仍为 `pipeline-draft`，`split.py::_EXAM_VERSIONS` 为空，官方入口 `load_exam()` 无法加载 v2.2。
- **修复**：
  - 将 `v2.2-gold.json` 与 `v2.2-mini.json` 的版本号更新为 `"version": "v2.2-gold"` 与 `"version": "v2.2-mini"`。
  - 在 `src/nutrienv/bench/split.py` 中注册 `EXAM_SPLIT_PATH = _ROOT / "data" / "splits" / "v2.2-gold.json"` 及 `_EXAM_VERSIONS = frozenset({"v2.2-gold", "v2.2-mini"})`。
  - 定义 `ALLOWED_TIERS = frozenset(EVALUATE_TIERS) | {"tier1", "tier2", "tier3"}`。

### 4. 为 Composite 任务补齐难度梯队元数据（Tier 1/2/3）
- **修复**：
  - **Tier-1 基础双意图（24 题）**：打标 `"tier": "tier1"`；
  - **Tier-2 高阶三意图（12 题）**：打标 `"tier": "tier2"`；
  - **Tier-3 终极四意图 Boss 题（4 题）**：`adr24-comp-8266/8267/9602/9603` 打标 `"tier": "tier3"`。

### 5. 修复评测脚本遥测 Tag（`scripts/eval_benchmark_suite.py`）
- **修复**：将 `allergen_violated` 修正为同时支持 `"allergy"` 与 `"FatalAllergyClash"`。
