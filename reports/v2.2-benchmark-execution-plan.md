# NutriEnv v2.2 Benchmark 评测执行方案与天梯打榜规划

## 一、 评测目标与设计原则
基于已冻结的权威百分制数据集 **`v2.2-gold`**（100 题）与精简验证集 **`v2.2-mini`**（20 题），全面衡量主流开源与商业大模型在真实场景下的**营养常识接地、6 维不等式背包搜索、多意图复合规划与临床安全红线把关**能力。

### 核心原则：
1. **Pass@1 黄金标准**：评测统一采用 `Temperature = 0.0` 贪心解码的 **Pass@1** 指标，考察 Agent 决策的确定性与鲁棒性，杜绝多采样成本浪费。
2. **极简协议盲测（ADR 0023 阶段二）**：仅提供 [react.py](file:///home/jzq/Projects/nutri-env/src/nutrienv/harness/react.py) 标准手册，严禁硬编码小抄字典，考察模型纯粹的常识推理与工具调用能力。
3. **分批次与成本控制**：
   - 先行运行 `v2.2-mini` 验证环境网络与格式兼容性；
   - 第一批次通过 Flash 与 Pro 对照组建立基线并核算 Token 成本；
   - 第二批次推进全量旗舰巅峰横评。

## 三、 评测指标与排行榜维度

每个模型评测将输出以下全景指标并生成独立评测报告：
1. **综合指标**：
   - **Pass@1**：总得分（0 ~ 100 分）；
   - **总耗时 (Wall Time)** 与 **单步延迟 (Per-step Latency)**；
   - **Token 消耗与单次成本 (Prompt / Completion / Reasoning Tokens & USD Cost)**。
2. **分题型通过率 (Family Pass Rate)**：
   - **Update** (5 题)：基础修改与幂等确认；
   - **Log** (15 题)：口语量词与 FNDDS 白名单物理接地；
   - **Evaluate** (20 题)：致命过敏拦截与宏量偏离预警；
   - **Recommend** (20 题)：动态余量不等式求解；
   - **Composite** (40 题)：多意图状态机流转（Tier-1 / Tier-2 / Tier-3 分层透视）。
3. **安全与效率红线**：
   - **致命过敏违规率 (Allergen Violation Rate)**；
   - **工具调用步数分布 (Step Efficiency, 预算 6/12/30 步)**；
   - **无效格式调用率 (Invalid Tool Call Rate)**。
